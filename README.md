# 🕹️ C++ Tic Tac Toe (i guess lol)

Simple C++ Tic Tac Toe game with AI, scoreboard, and menu system.

## 🚀 Features
- PvP mode
- AI mode (unbeatable)
- Score saving (file)
- Clean C++ structure

## ⚙️ Build & Run
make
make run
make clean

## 🎮 How to play
Pick 1–9 to place X or O on the board.

## 🤖 AI
Uses Minimax (never loses).

## 📁 Score file
data/scores.txt

## 🧠 Built with
C++, OOP, file handling
